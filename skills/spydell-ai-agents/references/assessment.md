# Оценка целесообразности ИИ-агента

## Уровень работы

- **задача** — одно проверяемое действие;
- **модуль** — связанная группа задач с локальным результатом;
- **процесс** — повторяемая последовательность модулей;
- **проект** — интеграция разных модулей с изменяемыми приоритетами;
- **интеграция систем** — координация взаимозависимых процессов в динамической среде.

Успешный пример задачи не подтверждает автономность процесса или проекта.

## Координаты агента

- **среда:** терминал или код, API, браузер, графический интерфейс, физический мир;
- **роль:** помощник, исполнитель, делегат, автономный оператор, координатор других агентов;
- **топология:** один агент, агент с субагентами, гетерогенная система;
- **горизонт:** сессионный, процедурный, долгоживущий;
- **надзор:** подтверждение каждого действия, контрольные точки, выборочный последующий аудит, вмешательство по инциденту.

Не называй систему автономной без описания пространства действий, ограничений и человеческого возврата в контур.

## Ворота пригодности

Неблагоприятный фактор требует уменьшения автономности, сужения задачи, усиления независимой проверки или пилота. Полный список — [detailed/assessment-gates.md](detailed/assessment-gates.md).

## Решение об автономности

1. помощник готовит варианты, человек действует;
2. агент действует только после подтверждения;
3. агент действует между заранее определёнными контрольными точками;
4. агент выполняет ограниченный процесс, человек проводит выборочный аудит;
5. агент работает самостоятельно, человек подключается по инциденту.

Повышай уровень только после доказательства надёжности предыдущего на репрезентативных данных и в условиях, близких к рабочим. Назови критерии повышения и автоматического понижения.
