# Происхождение

- Семейство Spydell — пользовательская разработка.
- Часть методов адаптирована из авторской коллекции пользователя `specialist-profiles`;
  пути к исходным файлам — в [skills/spydell/references/sources.md](skills/spydell/references/sources.md).
  Сама коллекция в репозиторий не входит.
- Схема OpenSpec и шаблоны получены из `@fission-ai/openspec` 1.14.1 и адаптированы под Spydell.
  Сверено 23 октября 2026 года с 1.14.3: upstream-схема `spec-driven` не изменилась.
  Оригинальная MIT-лицензия сохранена в [licenses/OpenSpec-MIT.txt](licenses/OpenSpec-MIT.txt).
- Навыки Matt Pocock, OpenSpec CLI и PyYAML не включены; их устанавливают из исходных источников.

Новая лицензия для авторских материалов пользователя не назначается.
Сохранение upstream-лицензии относится к соответствующим производным файлам OpenSpec.
